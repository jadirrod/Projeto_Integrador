# Brand spec — ZERO TRUST LAB

## Identidade

O ZERO TRUST LAB é um laboratório web acadêmico para explorar, de forma reproduzível, decisões de acesso em redes híbridas. A identidade visual deve transmitir rigor, transparência e experimentação controlada, sem imitar fabricantes de firewall, nuvem ou gestão de identidade.

## Assets

- **Marca principal:** `site/assets/images/brand-mark.svg`. Símbolo vetorial original, monocromático e transparente. Os quatro nós representam elementos de uma solicitação de acesso; o quadrado central representa o ponto de decisão. É um conceito visual do projeto, não uma marca registrada nem um logotipo oficial de fornecedor.
- **Screenshot de interface:** `site/assets/images/v0-dashboard-desktop.png`. Captura real do dashboard local em 1440 × 1200 px, sem execuções ou dados de laboratório. Representa o v0 e deverá ser substituída quando o produto funcional estiver pronto.
- **Imagens de produto:** não aplicável; trata-se de um produto digital.

## Sistema visual

- Fundo: `#0B1118`; superfícies principais: `#101821` e `#141F29`.
- Texto primário: `#E8F0F4`; texto secundário: `#A8B7C0`.
- Cor de marca: ciano-azulado `#32B7CF`.
- Estados semânticos: permitir `#36C98F`, negar `#F06470`, revisar `#E8B84C`. O significado também deve aparecer em texto; não depender só da cor.
- Tipografia de interface: `Aptos`, com fallback `Segoe UI` e sans-serif. Identificadores e dados técnicos usam `Consolas`, com fallback monoespaçado. Não há carregamento externo de fontes.

## Uso

Usar a marca SVG por `<img src="…">`, sem redesenhá-la por CSS. O tema padrão é escuro; o tema claro permanece como ajuste visual opcional. Evitar gradientes decorativos, brilho, animação contínua e ícones de fornecedor. Todos os números do v0 permanecem como “—” até haver resultados de simulação.

## Estado

A identidade e a tela mostradas são um primeiro conceito sujeito à revisão do autor. O screenshot é uma captura local do v0, não uma evidência de resultados experimentais.
